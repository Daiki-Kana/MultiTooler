# WebSlideSwitch - プレゼンコントローラー

スマホをWi-Fi経由でPCと接続し、Googleスライドの「進む」「戻る」をスマホから非接触でリモート操作できるプレゼンテーション支援ツールです。

---

## 特長

- **アプリのインストール不要**: スマホの標準カメラでPC画面のQRコードを読み取るだけで、ブラウザがコントローラーに早変わり。
- **Googleスライド完全対応**: アクティブなGoogleスライド（またはKeynote、PowerPoint等）へ超低遅延でキーストローク（矢印キー）を自動送信。
- **Ferrariデザイン準拠UI**: Rosso Corsa（赤）とニアブラック（#181818）による洗練されたデザイン。暗い会場でも誤操作しにくい大型ボタン設計。
- **触覚＆スワイプ操作**: タップ時の振動フィードバック（Haptic Vibration）に加え、左右スワイプでも進む・戻るが可能。
- **スリープ防止機能内蔵**: プレゼン中にスマホ画面が暗くならないよう、Screen Wake Lock APIで常時点灯を維持。

---

## 使い方

### 1. サーバーの起動
フォルダ内の `start.bat` をダブルクリックして起動します。
自動的にブラウザが立ち上がり、ダッシュボード（`http://localhost:3000`）が開きます。

### 2. Googleスライドの準備
PCで操作したいGoogleスライドを開き、プレゼンテーション表示（全画面表示）にしておきます。

### 3. スマホの接続
PCダッシュボードに表示されているQRコードを、**PCと同じWi-Fiに接続したスマホのカメラ**でスキャンします。

### 4. 操作
スマホ画面に表示される以下のボタンで操作します:
- **NEXT ▶ (赤色の巨大ボタン)**: 次のスライドへ進む（右矢印キー）
- **◀ PREV**: 前のスライドへ戻る（左矢印キー）
- **暗転 [B]**: 画面を一時的に真っ暗にして聴衆の注目を集める
- **白転 [W]**: 画面を一時的に白にする
- **画面スワイプ**: 画面を左右にスワイプすることでも進む・戻る操作が可能です。

---

## 動作要件
- Node.js (v18以上推奨)
- Windows 10 / 11
- PCとスマホが同一のWi-Fiネットワーク（またはスマホのテザリング）に接続されていること
